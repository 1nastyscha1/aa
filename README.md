## 1. Алгоритмы поиска

Алгоритмы поиска позволяют определить, присутствует ли заданный элемент в массиве данных.

| Файл | Язык | Алгоритм | Описание | Сложность |
|-----|------|----------|----------|----------|
| Binary Search.java | Java | Двоичный поиск | Деление отсортированного массива пополам | O(log n) |
| Fibonacci Search.py | Python | Поиск Фибоначчи | Использует последовательность Фибоначчи для выбора индексов | O(log n) |
| Interpolation Search.java | Java | Интерполяционный поиск | Предполагает равномерное распределение значений | O(log log n) |
| Sequential Search.py | Python | Последовательный поиск | Проверка элементов по очереди | O(n) |

**Ключевая идея:**  
Если данные **отсортированы**, стоит использовать **двоичный или интерполяционный поиск**.  
Если данные **не упорядочены** — остаётся **линейный поиск**.

## 2. Алгоритмы сортировки

Сортировка позволяет расположить элементы массива по возрастанию или убыванию.

| Файл | Язык | Алгоритм | Принцип | Сложность |
|-----|------|----------|---------|----------|
| Bubble Sort.py | Python | Пузырьковая сортировка | Обмен соседних элементов | O(n²) |
| Insertion Sort.java | Java | Сортировка вставками | Вставка элемента в отсортированную часть массива | O(n²) |
| SelectionSort.cpp | C++ | Сортировка выбором | Поиск минимального и установка на место | O(n²) |
| Shell Sort.py | Python | Сортировка Шелла | Сортировка с уменьшающимся шагом | ~O(n log n) |
| Merge Sort.java | Java | Сортировка слиянием | Рекурсивное разделение массива на части | O(n log n) |
| Quick Sort.java | Java | Быстрая сортировка | Разбиение относительно "опорного" элемента | O(n log n) в среднем |
| Heap Sort.cpp | C++ | Сортировка кучей | Использование двоичной кучи | O(n log n) |

**Вывод:**  
- Сортировки **O(n²)** подходят для учебных целей, но не для больших данных.  
- Реально эффективные на практике: **Merge Sort**, **Quick Sort**, **Heap Sort**.

| Алгоритм | Оптимальное применение | Сложность |
